==========================================================
   ShopSystem  -  راهنمای نصب و اجرا
==========================================================

این برنامه سه بخش را با هم و به‌صورت یکجا اجرا می‌کند:
   ۱) سرویس API فروشگاه  (روی  http://127.0.0.1:8000)
   ۲) ربات بله
   ۳) ربات تلگرام

نیازها: ویندوز، SQL Server (روی همین سیستم) و دسترسی اینترنت.
نصب پایتون لازم نیست؛ همه‌چیز داخل خود برنامه است.


----------------------------------------------------------
گام ۱) فایل .env را بسازید و پر کنید
----------------------------------------------------------
در همین پوشه فایلی به نام  .env.example  وجود دارد:

  ۱. از آن یک کپی بسازید و نام کپی را دقیقاً بگذارید:  .env
     (مراقب باشید ویندوز پسوند اضافه نکند: .env.txt اشتباه است)
  ۲. آن را با Notepad باز کنید و مقادیر را پر کنید.
  ۳. فایل را با کدگذاری UTF-8 ذخیره کنید.

مهم‌ترین خطوطی که باید پر شوند:

   TELEGRAM_TOKEN = توکن ربات تلگرام (از @BotFather)
   BALE_TOKEN     = توکن ربات بله (از BotFather داخل برنامه بله)
   BOT_API_KEY    = یک رشته تصادفی و طولانی (کلید دسترسی ربات‌ها)
   SITE_API_KEY   = یک رشته تصادفی دیگر
   ADMIN_API_KEY  = یک رشته تصادفی دیگر (برای کارهای مدیریتی)
   ADMIN_CHAT_IDS = آیدی عددی چت مدیر شما، مثال:  telegram:123456789
   DB_SERVER      = .\SQLEXPRESS
   DB_NAME        = hesab5 t
   SHOPAPI_URL    = http://127.0.0.1:8000

نکته: اگر فقط یکی از دو ربات را می‌خواهید، خط توکن ربات دیگر را
خالی بگذارید؛ برنامه فقط همان‌هایی را اجرا می‌کند که توکن دارند.

نکته: توکن تلگرام در ایران بدون پروکسی کار نمی‌کند.
اگر پروکسی دارید آدرس آن را در PROXY_URL بنویسید.


----------------------------------------------------------
گام ۲) برنامه را اجرا کنید
----------------------------------------------------------
روی فایل  ShopSystem.exe  دوبار کلیک کنید.


----------------------------------------------------------
گام ۳) پنجره سیاه را نبندید
----------------------------------------------------------
یک پنجره مشکی (کنسول) باز می‌شود که این پیام را نشان می‌دهد:

     ShopSystem is running. Do not close this window.
     Check app.log for errors.

  * این پنجره را نبندید؛ بستن آن یعنی خاموش شدن ربات‌ها و API.
  * برای خاموش کردن برنامه، کلیدهای Ctrl و C را با هم بزنید.
  * همه رویدادها و خطاها در فایل  app.log  در همین پوشه ذخیره
    می‌شوند. اگر مشکلی پیش آمد، اول همان فایل را ببینید.


----------------------------------------------------------
گام ۴) بررسی درستی کار
----------------------------------------------------------
مرورگر را باز کنید و این آدرس را ببینید:

     http://127.0.0.1:8000/docs

اگر صفحه مستندات API باز شد، یعنی سرویس سالم است و در حال کار.

برای بررسی سریع با PowerShell:

     Invoke-RestMethod http://127.0.0.1:8000/health

     Invoke-RestMethod http://127.0.0.1:8000/groups -Headers @{ "X-API-Key" = "همان BOT_API_KEY" }

سپس در تلگرام یا بله به ربات خود پیام  /start  بدهید.


----------------------------------------------------------
نکات ایمنی مهم
----------------------------------------------------------
۱) مقدار ACCOUNTING_WRITE_ENABLED به‌صورت پیش‌فرض  false  است.
   در این حالت هیچ سفارشی در نرم‌افزار حسابداری ثبت نمی‌شود؛
   برنامه تراکنش را کامل اجرا می‌کند و بعد آن را برمی‌گرداند
   (برای آزمایش امن است).

۲) تا زمانی که همه‌چیز را با یک سفارش آزمایشی تست نکرده‌اید،
   آن را true نکنید. با true شدن، سفارش‌ها واقعاً در حسابداری
   ثبت می‌شوند.

۳) فایل .env حاوی رمزها و توکن‌ها است. آن را برای کسی نفرستید و
   در جای عمومی قرار ندهید.


----------------------------------------------------------
اگر برنامه باز نشد یا ربات جواب نداد
----------------------------------------------------------
  * فایل app.log را باز کنید و آخرین خطوط را بخوانید.
  * اگر نوشته بود «no .env file found» یعنی فایل .env ساخته نشده
    یا نامش اشتباه است (باید دقیقاً .env باشد).
  * اگر خطای دیتابیس بود:
      - درست بودن DB_SERVER و DB_NAME را بررسی کنید.
      - مطمئن شوید سرویس SQL Server در حال اجراست.
      - مطمئن شوید حساب ویندوزی شما به آن دیتابیس دسترسی دارد.
  * اگر ربات تلگرام جواب نداد: در ایران نیاز به PROXY_URL دارد.
  * اگر پورت 8000 اشغال بود، در .env مقدار API_PORT را عوض کنید
    (و SHOPAPI_URL را هم با همان پورت به‌روز کنید).
